# 💾 Saytni Saqlash (HTML + CSS)

**BeautifulSoup** yordamida veb-sahifani yuklab, HTML va CSS fayllarini lokal saqlovchi skript.

---

## ✨ Imkoniyatlar

- 🌐 **Sahifani yuklash:** URL bo'yicha HTML olish
- 🎨 **CSS'larni saqlash:** tashqi stillarni lokal nusxalash
- 🔗 **Havolalarni qayta ishlash:** `urljoin` orqali to'g'ri yo'llar
- 📁 **Xavfsiz fayl nomlari:** noto'g'ri belgilarni tozalash

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **requests** | Sahifani yuklash |
| **BeautifulSoup (bs4)** | HTML tahlil |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/Save-HTML-CSS-site-.git
cd Save-HTML-CSS-site-
pip install requests beautifulsoup4
```

---

## ▶️ Ishga tushirish

```bash
python main.py
```

Saqlangan natija `saved_page/` papkasida (HTML + CSS) paydo bo'ladi.
